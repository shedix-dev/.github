## shedix

**A real computer in the cloud for your coding agents.** Started with one tap, or by your agent itself, and ready for
how you work: a whole Linux machine with a desktop, root, Docker and its own address, Claude Code and Codex installed.
Start one at [shedix.dev](https://shedix.dev).

*Built by builders, for builders.*

- **Give your agent the skill:** `npx skills add shedix-dev/skills` ([skills](https://github.com/shedix-dev/skills))
- **Or paste one line into any agent:** `Use shedix for this: shedix.dev/SKILL.md`

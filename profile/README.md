## shedix

**Cloud Linux machines for Claude Code, Codex and other coding agents.** Full Ubuntu with root and Docker, keeps
working after your laptop closes, sleeps when idle. Start one at [shedix.dev](https://shedix.dev).

- **Give your agent the skill:** `npx skills add shedix-dev/skills` ([skills](https://github.com/shedix-dev/skills))
- **Or paste one line into any agent:** `Use shedix for this: shedix.dev/SKILL.md`
